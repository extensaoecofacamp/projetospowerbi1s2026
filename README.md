# projetospowerbi1s2026
Este repositório tem como objetivo compartilhar a produção das atividades de extensão que foram desenvolvidas no 1º Semestre de 2026, na FACAMP.

Dois grupos desenvolveram tutoriais de utilização do SIDRA - IBGE por meio do Power BI - Microsoft. 

Os arquivos tutoriais bem como os .pbix estão disponibilizados para livre utilização. Pede-se apenas que seja feita a devida referência ao material e a este repositório.
