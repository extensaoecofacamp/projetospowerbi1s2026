# projetospowerbi1s2026
Este repositório tem como objetivo compartilhar a produção das atividades de extensão que foram desenvolvidas no 1º Semestre de 2026, na FACAMP.

Dois grupos desenvolveram tutoriais de utilização do SIDRA - IBGE por meio do Power BI - Microsoft.

O arquivo PIB_Conceitos.md apresenta os principais conceitos relacionados ao PIB e aos dados das Contas Nacionais Trimestrais - CNT/IBGE utilizados nos dashboards.

Em cada pasta, contém um arquivo .md com o roteiro de elaboração, passo-a-passo, do dashboard e o arquivo .pbix com o dashboard para downnload.

O Grupo 1, composto pelos alunos Elisa Monteiro De Souza Furtado, Fabricio De Castro e Marina Patelli Miotto, elaborou um dashboard em Power BI analisando a evolução e composição do PIB Anual, a partir das Contas Nacionais Trimestrais - CNT/IBGE. 

O Grupo 2, composto pelos alunos Douglas Montanheiro Filho, João Paulo Lima Pondian, Pedro Campos Lambertini e Pedro Henrique Da Cruz Olmedo, elaborou um fashboard em Power BI analisando a evolução do PIB trimestral e sua composição, a partir das Contas Nacionais Trimestrais - CNT/IBGE.

Os arquivos tutoriais bem como os .pbix estão disponibilizados para livre utilização. Pede-se apenas que seja feita a devida referência ao material e a este repositório.
